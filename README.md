# UNIVERSAL NACA AIRFOIL GENERATOR

## Project Description

The Universal NACA 4-Digit Airfoil Generator is a Python application that generates and visualizes any valid NACA 4-digit airfoil using the standard NACA equations. It is designed as an educational and engineering tool for exploring airfoil geometry and producing accurate airfoil models.

## Features

- Generates any valid NACA 4-digit airfoil.
- Supports both symmetric (e.g., NACA 0012) and cambered (e.g., NACA 2412, NACA 4415) airfoils.
- Plots the upper surface, lower surface, and camber line.
- Exports airfoil coordinates as a CSV file.
- Saves the generated airfoil plot as a PNG image.
- Validates user input and rejects invalid NACA codes.

## Usage

1. Run the Python script.
2. Enter a valid 4-digit NACA airfoil code (e.g., 0012, 2412, or 4415).
3. The program validates the input.
4. The airfoil is generated and displayed.
5. A CSV file containing the airfoil coordinates is automatically created.
6. A PNG image of the generated airfoil is automatically saved.
